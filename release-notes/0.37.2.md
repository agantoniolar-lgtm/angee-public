## After installing

- If the project wants to delegate, copy the bullet that starts with "**Delegating is the default, while no class A decision is pending on the work.**" from "Git conventions" in `ae-kit-templates/CLAUDE.md.template` into the same section of the project's `CLAUDE.md`, in English and word for word, and add `.claude/worktrees/` to `.gitignore`. The installer never touches `CLAUDE.md`, so an installed project does not get the line any other way. Both edits need the owner's permission. A project that keeps a single writer skips this step. If the project goes straight to 0.38.0, skip the `.gitignore` edit: 0.38.0's `apply-branch-policy.mjs delegate` makes it.
- If the project delegates, copy `logs/subagents/` from a builder's worktree into the main checkout before removing the worktree: in this version the subagent collector (R36) writes the transcript inside the worktree, and it is lost with it. If the project goes straight to 0.38.0, skip this step: in 0.38.0 the collector writes to the main checkout.
- **Only a project whose `.ae-kit-customized` lists `scripts/check-log-layout.mjs`:** keep the kit's `scripts/check-log-layout.mjs` and remove its line from `.ae-kit-customized`: the kit now ships the fix the project made, generalized to every worktree. Ask the owner before committing the change. Skip this step if it is already done.
